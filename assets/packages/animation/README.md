# Layout Projection / Animation

Framework-agnostic implementation of Layout Animation, powered by Layout Projection

```sh
npm i @layout-projection/{core,animation}
```

---

Layout Animation is a special kind of animation that animates the position and size of an element, while preserving its visual styles. Such animation can be achieved by performing Layout Projection on the element in each animation frame.

This package offers an extensible framework for performing concurrent layout animations on multiple elements.
